# Dhanush Portfolio

A personal portfolio website built with React and Vite to showcase a developer's profile, technical skills, projects, education, and contact information.

## About

This portfolio belongs to Dhornagambala Dhanush, a B.Tech Computer Science and Engineering student specializing in AI & ML. The website is designed to present work, experience, and technical capabilities in an elegant and modern format.

## Highlights

- Personal branding and hero section
- Skills and technology stack overview
- Project showcase with links
- Experience and education sections
- Contact and social links
- Responsive single-page layout

## Tech Stack

- React
- Vite
- Lucide React Icons
- CSS for styling and layout

## Project Structure

```bash
.
├── src/
│   ├── App.jsx
│   ├── main.jsx
│   └── styles.css
├── public/
├── index.html
├── package.json
├── vite.config.js
└── README.md
```

## Features

- Modern dark-themed portfolio design
- Smooth scrolling navigation
- Animated reveal effects
- Project cards and skill meters
- Downloadable resume option

## Run Locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Customize

Update the profile information in `src/App.jsx` for:

- Name
- Email
- GitHub profile
- LinkedIn profile
- Skills and projects
- Resume link and contact details
